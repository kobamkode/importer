# Issue Tracker

Issues live in [beads](https://github.com/steveyegge/beads), tracked via the `bd` CLI in
this repo's issue database. Create issues with `bd create` (or `bd q` for quick capture
returning just an ID), list work with `bd list` / `bd ready`, inspect with `bd show <id>`,
and close with `bd close <id>`. Use `bd dep` for dependency links and `bd label`/`bd tag`
for labels. Don't create issues in GitHub or as markdown files — always go through `bd`
so dependency tracking stays intact.
